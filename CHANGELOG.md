# Changelog

All notable changes to EdgeBrain are documented in this file.

## [1.0.0] - 2025-06-05

### Added
- **Edge AI Inference Engine** — Run ML models locally with sub-100ms latency
- **ESP32 Firmware** — Arduino/C++ firmware for edge devices
- **Device Simulator** — Simulate IoT devices for testing
- **Backend API** — FastAPI-based REST API with WebSocket support
- **Frontend Dashboard** — React-based real-time monitoring UI
- **Docker Support** — Full Docker Compose stack (backend, frontend, PostgreSQL, Redis, MQTT)
- **Model Pipeline** — Load, preprocess, infer, and postprocess ML models
- **MQTT Integration** — Real-time sensor data ingestion and command publishing
- **Rule Engine** — Configurable decision rules for autonomous actions
- **Multi-protocol Support** — HTTP, WebSocket, MQTT for flexible integrations
- **Device Management** — Register, monitor, and control edge devices
- **Alert System** — Threshold-based alerts with notification channels
- **Data Logging** — Time-series data storage and visualization
- **Plugin Architecture** — Extend with custom sensors, actuators, and models
